---
title: Keyboard shortcuts
description: Keyboard shortcuts in the main window.
---

| Shortcut | Action |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | [Quick connect](../connecting/#quick-connect): type, <kbd>Enter</kbd> connects, <kbd>Shift</kbd>+<kbd>Enter</kbd> only selects the entry, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>/<kbd>U</kbd>/<kbd>H</kbd> copy password/user/host, <kbd>F2</kbd> edits, <kbd>Esc</kbd> closes |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Focus the search box (filters the list) |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Pin or unpin the selected entry |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New entry |
| <kbd>Esc</kbd> (in the search box) | Clear the search |
| <kbd>↓</kbd> (in the search box) | Move into the tree |
| <kbd>Enter</kbd> (in the tree) | Connect to the selected entry; on a folder, expand or collapse it |
| Double-click (in the tree) | Connect to the entry; on a folder, expand or collapse it |
| <kbd>←</kbd> / <kbd>→</kbd> (in the tree) | Collapse / expand the folder; <kbd>←</kbd> on an entry jumps to its folder |
| <kbd>↑</kbd> / <kbd>↓</kbd> (in the tree) | Previous / next visible row |
| <kbd>Del</kbd> (in the tree) | Delete the selected entry (after confirmation) |
| <kbd>F2</kbd> | Edit the selected entry |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy the selected account's password (cleared from the clipboard after 30 s) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>U</kbd> | Copy the selected account's user name |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Copy the selected entry's host (`host:port` for a non-default port) |
| <kbd>F5</kbd> | Sync with the shared database and refresh presence |

The fastest way to connect is <kbd>Ctrl</kbd>+<kbd>K</kbd>, a few letters of the name, host or folder, and
<kbd>Enter</kbd>. The search box has focus when the app starts: type part of a name, press <kbd>↓</kbd> to move to
the tree, pick the entry with the arrow keys and press <kbd>Enter</kbd> to connect. The main window shows each shortcut next
to its button.

In the editor and settings dialogs, <kbd>Ctrl</kbd>+<kbd>S</kbd> (or <kbd>Enter</kbd>) saves, <kbd>Esc</kbd>
cancels, and <kbd>Ctrl</kbd>+<kbd>Tab</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> move between the
sections listed on the left.
