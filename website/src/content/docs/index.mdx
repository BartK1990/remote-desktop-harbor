**Remote Desktop Harbor** is a fast, portable Windows app that keeps your Remote Desktop connections and
credentials in one encrypted catalog, opens them in the regular Windows Remote Desktop client with one click, and —
with a shared database — shows your team who is currently connected where.

## Features at a glance

- **Two entry kinds** — a full *RDP connection* (host + `.rdp` settings + credentials) or *credentials only*.
  Existing `.rdp` files can be imported.
- **Local or shared storage** — a local SQLite vault, or a shared SQL Server / Azure SQL database with an automatic
  local offline copy. Other SQL engines can be plugged in.
- **Works offline** — when the shared database is unreachable you can still browse, search, copy and connect from
  the local copy.
- **Sign-in** — your Windows account (automatic single sign-on) or Microsoft Entra ID through the Windows broker.
- **Built for speed** — the main window is visible in under a second, and catalogs with 10 000 entries stay smooth.

## How it works

```
 ┌──────────────────────────┐   one click   ┌───────────────────────────────┐
 │ Remote Desktop Harbor    │ ────────────► │ mstsc.exe (normal RDP window) │
 │  catalog · search · copy │               └───────────────────────────────┘
 └────────────┬─────────────┘    password via Windows Credential Manager
              │ encrypted rows only
     ┌────────┴─────────┐
     │ local SQLite     │  ◄── sync ──►  shared SQL Server / Azure SQL (optional)
     │ vault / cache    │                + "who is connected" presence records
     └──────────────────┘
```
